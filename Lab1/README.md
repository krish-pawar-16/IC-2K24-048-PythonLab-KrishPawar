2. Greeting Program
Aim
To take the user's name, age, and city as input and display them in a single sentence.

Logic
Take the name, age, and city from the user using input().
Use an f-string to combine all three values into one sentence.

Sample Input / Output

Input:
Enter your name: Krish
Enter your age: 20
Enter your city: Indore

Output:
My name is Krish, I am 20 years old and I live in Indore.

6. Escape Sequence Practice
Aim
To use escape sequences such as \t and \n to format a simple receipt.

Logic
Using \t to create spacing between the item name and price.
Using \n to move the output to a new line and display the receipt in a readable format.

Sample Input / Output
No input is required.

Output:

Item    Price
Pen     20
Notebook        50
